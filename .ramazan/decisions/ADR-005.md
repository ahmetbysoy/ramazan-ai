# ADR-005

## Decision
Repository Inclusion Policy: Commit Deterministic Specifications & Task Artifacts; Exclude Ephemeral Runtime Caches and Logs.

## Context
Spec Section 16 & Section 27 require immutable auditability for architectural decisions, task lifecycle states, and worker memories. However, runtime log streams, ephemeral chat sessions, and temporary rollback snapshots pollute git history if not properly filtered.

## Alternatives
- Ignore all of `.ramazan/` in `.gitignore` (loses project state, tasks, and ADR history).
- Commit everything including raw terminal logs, chat history, and temporary file snapshots.
- Commit deterministic project artifacts (`config.json`, `architecture.md`, `decisions/`, `tasks/`, `memory/`, `reviews/`, `state.json`) while strictly ignoring runtime logs (`.ramazan/logs/`), snapshots (`.ramazan/snapshots/`), and ephemeral chat sessions (`chat_history.json`) (Chosen).

## Reason
1. Task files, ADRs, and state files are essential for project reproducibility, CI/CD verification, and deterministic orchestration.
2. Log files and rollback snapshots are transient runtime artifacts that fluctuate on every execution and do not represent codebase truth.
3. Chat history is per-session and can contain developer-specific queries.

## Consequences
- `.gitignore` explicitly ignores `.ramazan/logs/`, `.ramazan/snapshots/`, `.ramazan/tests/`, and `.ramazan/chat_history.json`.
- `.ramazan/decisions/`, `.ramazan/tasks/`, `.ramazan/memory/`, and `.ramazan/reviews/` remain tracked as first-class audit artifacts.
